### Unidad 1: Fundamentos de Computadoras
- Arquitectura de computadoras (RISC vs CISC)

- Buses de datos
- Memoria: RAM, ROM, caché
- Almacenamiento

### Unidad 2: Sistemas Operativos y Redes
- Sistema de Nombres de Dominio (DNS)
- Funcionamiento de servidores Web
- Conceptos de Internet
- Protocolo TCP/IP

### Unidad 3: Sistemas Operativos
- Cuadro comparativo de Sistemas Operativos
- Windows, Linux, Mac, iOS, Android
- Aplicaciones prácticas

### Unidad 4: Tecnologías Emergentes
- Internet de las Cosas (IoT)
- Metadatos y cabeceras de archivos
- Bases de datos SQL vs NoSQL
- Redes Neuronales Artificiales
